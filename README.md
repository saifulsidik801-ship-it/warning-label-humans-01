The funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer. The program scores several candidate lines against the judge's published criteria — the laugh landing in the last few words, true about people in general, sounding like a real printed label — and writes the winning line to `entry.txt`.

The winning label:

> WARNING: May spontaneously announce 'I'm not even mad' while visibly furious, then bring it up again in 2031.

## Run it

```sh
python3 main.py
```

It writes the winning one-line warning label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default).
